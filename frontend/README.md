# Sklad frontend

Учёт закупок: React 18 + TypeScript + Redux Toolkit (RTK Query) + Ant Design 5.
Статику отдаёт Node (Express), он же проксирует `/api/*` на Spring-бэкенд, поэтому CORS не нужен.

## Запуск

```bash
cd frontend
npm install

# разработка: Vite на :5173, /api проксируется на http://localhost:8080
npm run dev

# production: сборка в dist/ и Node-сервер на :3000
npm run build
npm start
```

Переменные окружения Node-сервера (см. `.env.example`): `PORT` (по умолчанию 3000), `BACKEND_URL` (по умолчанию `http://localhost:8080`).

## Проверки

```bash
npm run typecheck   # tsc
npm test            # vitest: unit-тесты + сквозной сценарий с замоканным бэкендом
```

## Как устроено

- `src/api/skladApi.ts` — RTK Query, все эндпоинты бэкенда и разбор ошибок.
- `src/features/drafts` — черновики новых записей по датам, слайс и thunk синхронизации.
- `src/features/ui` — тема, язык, выбранная дата, режим просмотра/редактирования, автосоздание.
- `src/lib/matching.ts` — сопоставление введённых значений со справочниками, состояния ячеек, валидация строки.
- `src/components` — лента дат, остров с таблицей (десктоп) или карточками (мобилка), редактируемые ячейки с подсказками, нижняя панель.
- `src/i18n` — словари ru/en и плюрализация.
- `server/index.mjs` — Express: статика + прокси.

Черновики и настройки интерфейса хранятся в `localStorage`, так что перезагрузка страницы их не теряет.

## Сценарий работы

1. Сверху лента дат, по умолчанию выбран сегодняшний день. Под ней записи за этот день.
2. Переключатель «Редактирование» открывает добавление строк. Сохранённые записи при этом только для чтения.
3. Значение, которого нет в справочнике, подсвечивается. Подсказка предлагает «Добавить» или «Выбрать из существующих». Тумблер «Автосоздание» отключает подсказки: всё новое создаётся автоматически.
4. «Синхронизировать» в нижней панели доступна, когда нерешённых новых значений нет. Сначала создаются справочные записи, затем закупки по одной. Успешные строки уходят из черновиков, ошибочные остаются с текстом ошибки.
5. «Отменить» удаляет черновики выбранного дня и возвращает в просмотр.

## Проверка вёрстки

```bash
npm run shots   # нужен запущенный npm start и Google Chrome
```

Скрипт открывает приложение в headless Chrome на ширинах 375, 768, 1024 и 1366, переключает режим редактирования, добавляет две строки и складывает PNG в `screenshots/`. В консоль выводится ширина документа: если она больше ширины окна, вёрстка переполняется.
